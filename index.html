ГРАНД СН — будівельні матеріали

Постачання будівельних матеріалів для професійного будівництва та ремонту.

▦ Будівельні суміші

Штукатурки, шпаклівки, клеї, ґрунтовки та інші матеріали для оздоблення.

▤ Утеплювачі

Теплоізоляційні та звукоізоляційні матеріали для будівельних робіт.

⌘ Кріплення та метизи

Саморізи, болти, гайки, дюбелі, шпильки та інші кріпильні елементи.

◯ Труби та комплектуючі

Труби, фітинги та комплектуючі для монтажу інженерних систем.

⌁ Електротехнічні матеріали

Кабелі, автоматика, гофра та комплектуючі для електромонтажу.

▣ Будівельна хімія

Герметики, монтажна піна, фарби, клеї та спеціальні склади.

▤ Метал та металопрокат

Арматура, профільні труби, металеві вироби та інші матеріали.

▥ Пиломатеріали

Брус, дошка та інші дерев’яні матеріали для будівництва.
