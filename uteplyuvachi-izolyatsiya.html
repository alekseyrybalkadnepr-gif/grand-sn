Утеплювачі та ізоляція

Тепло-, звуко- та гідроізоляційні матеріали для будівельних об’єктів.

Матеріали для утеплення та ізоляції допомагають підвищити енергоефективність, захистити конструкції та забезпечити необхідний рівень комфорту.

Тепло- та звукоізоляція

У асортименті є акустична ізоляція KNAUF, звукоізоляційна самоклеюча стрічка XPE та інші рішення для ізоляції конструкцій.

Приклади: KNAUF AKU board M, KNAUF акустична вата, XPE 8 мм.

Ізоляція труб

Комплекти ізоляції стиків та комплектуючі для теплоізольованих труб у різних типорозмірах.

Приклади: Комплекти ЕР-1 та ЕР-3, відводи для теплоізольованих труб.

Супутні матеріали

Кріплення теплоізоляції та матеріали для виконання монтажних робіт.

Приклади: KI-MP 10x180, дюбелі Fast-Fix для теплоізоляції.

Основні виробники та торгові марки

KNAUF, Siltek, Fast-Fix.
